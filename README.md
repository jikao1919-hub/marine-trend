# Marine Trend（デモ版）

Scopus Search API を使い、指定した検索条件に合う論文について

- 年別の論文数の推移
- よく登場する著者・よく掲載されている雑誌・所属機関の国
- タイトルによく出る語（権限があれば著者キーワードも）
- 論文一覧（タイトル・著者・雑誌・年・被引用数、Scopus レコードへのリンク付き）

を表示する、1ページだけの Web アプリのたたき台です。HTML / CSS / JavaScript のみで、ビルドやサーバーは不要です。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目（ライト/ダークモード対応） |
| `app.js` | Scopus API の呼び出し、集計、描画 |
| `.nojekyll` | GitHub Pages で Jekyll 処理を無効にする空ファイル |

## 仕組み

- API 呼び出しは**利用者のブラウザから直接** `api.elsevier.com` に送ります。このサイト側にサーバーはなく、入力された API キーはどこにも保存・送信しません（「このタブを閉じるまで保持」にチェックした場合のみ、そのタブの sessionStorage に入ります）。
- 年別の件数は、`(検索式) AND PUBYEAR = 年` を `count=1` で年ごとに問い合わせ、総件数だけを読んでいます。15年分なら15リクエスト程度です。
- 著者・雑誌などの集計は、並び順（被引用数順など）の上位 25〜200 件の書誌情報から行います。全件ではありません。
- まず `view=COMPLETE`（全著者・著者キーワードあり）で取得を試み、権限がなければ `view=STANDARD`（筆頭著者のみ）に切り替えます。
- 「ダミーデータで表示」は画面確認用の架空データです。API キーがなくても動きます。

## 使い方

1. [Elsevier Developer Portal](https://dev.elsevier.com/) で API キーを発行する
2. ページを開き、API キーと検索語・期間を入力して「検索して分析」
3. Scopus を契約している組織のネットワーク内から使うと、取得できる項目が増えます

ローカルで試す場合は、リポジトリのフォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000` を開きます。

## GitHub Pages での公開手順

1. リポジトリの **Settings → Pages** を開く
2. **Build and deployment** の Source を **Deploy from a branch** にする
3. Branch を **main**、フォルダを **/ (root)** にして Save
4. 1〜2分後、`https://jikao1919-hub.github.io/marine-trend/` で公開されます

## 利用条件・注意点（必ず確認）

Elsevier の [API Use Policies](https://dev.elsevier.com/policy.html) では、Scopus のデータを Web サイトに表示する用途について、無料・非商用・広告なし、利用者のブラウザから直接 API を呼ぶ、Scopus レコードへリンクする、などの条件が定められています。一方で「誰でも任意の条件で検索できる分析ツール」はポリシーに明記されたユースケースにそのまま当てはまらないため、**社外に広く公開する前に、所属組織の図書館担当・契約窓口を通じて Elsevier に用途を確認してください。**

このデモでは次の点に配慮しています。

- 書誌情報（タイトル・著者・雑誌・年・被引用数・DOI）のみを扱い、抄録は取得・表示しない
- 取得したデータをサーバーやストレージに保存しない
- 各論文から Scopus のレコードにリンクし、出典（Scopus）を明記する
- API キーは利用者自身が発行したものを使う
